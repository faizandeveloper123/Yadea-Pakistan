HOW LEADS ARE FOUND
-------------------
  - DB view v_leads  = contacts where is_lead=1 OR contact_type='Lead'
                       OR tagged 'warm lead' / 'hot lead' / 'cold lead'
  - UI "Leads" tab   -> GET /api/leads (searchable by name/phone/email/tag)
  - SQL quick find   -> SELECT * FROM v_leads WHERE name LIKE '%term%' OR tags LIKE '%term%';
